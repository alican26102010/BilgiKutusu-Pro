# BilgiKutusu Pro'ya Katkıda Bulunma

BilgiKutusu Pro, internet bağlantısı olmadan bilgi kaynaklarına erişimi kolaylaştırmayı amaçlayan bir projedir.

## Nasıl katkı sağlanır?

1. Önce GitHub'da bir Issue açarak önerinizi veya hatayı açıklayın.
2. Depoyu fork edin, değişikliklerinizi ayrı bir dalda hazırlayın.
3. Kurulum talimatlarını ve mevcut işlevleri bozmadığınızı kontrol edin.
4. Değişikliklerinizi açıklayan bir Pull Request gönderin.

## Katkı ilkeleri

- Katkılar ücretsiz ve ticari olmayan kullanım lisansı koşullarıyla paylaşılmalıdır.
- Başkasına ait telifli kitap, video, harita veya diğer dosyaları dağıtım izni olmadan eklemeyin.
- Parola, API anahtarı, kişisel bilgi veya gerçek ağ kimlik bilgilerini depoya eklemeyin.
- Değişiklikleri mümkün olduğunca açık ve belgeli tutun.
- Projede yapay zekâ bileşeni önerilmemektedir; proje çevrimdışı bilgi erişimine odaklanır.

## Lisans

Katkı gönderenler, kendi katkılarını deponun `LICENSE` dosyasında belirtilen koşullarla yayımlamaya yetkili olduklarını kabul ederler. Katkı sahiplerinin kendi eserleri üzerindeki telif hakları saklıdır.
